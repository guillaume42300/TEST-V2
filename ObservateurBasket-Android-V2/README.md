# Observateur Basket V2

Version native Android conçue pour l'observation d'un match de basket.

## V2 inclut
- Page administrative : match, équipes, niveau, R1/R2.
- Début de match.
- Boutons FAUTE, VIOLATION, MÉCA, GESTION, AUTRE.
- Dictée vocale avec bouton « J'AI FINI ».
- Détection des acteurs A1-A99 / B1-B99 dans la dictée.
- Vrai terrain de basket avec acteurs déplaçables.
- R1 et R2 toujours disponibles.
- Bouton FIN DE QUART-TEMPS avec dictée du ressenti.
- Quatre fins de période : Q1, Q2, Q3, Q4 = fin du match.
- Conservation locale des notes.
- Écran des anciens dossiers.
- Rapport texte partageable/imprimable.
- Préparation des données pour une future synthèse IA sécurisée.

## Important
La V2 ne place volontairement aucune clé OpenAI/ChatGPT dans l'APK. La vraie synthèse IA sera branchée via un service sécurisé dans une prochaine étape, afin de ne pas exposer une clé API personnelle.
